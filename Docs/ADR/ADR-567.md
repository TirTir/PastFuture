# ADR-567 Universal 3D 템플릿 정리 범위

- Status: Accepted
- SourceStep: 17 / M0 (2026-11-25, 사용자 승인)
- Related: ADR-476, ADR-477, ADR-478 / Handover 14.2, 16-17

## Context
Unity Hub의 Universal 3D 템플릿(`com.unity.template.3d-cross-platform` 17.0.14)에는 예제 자료와 이 프로젝트 방향(PC, GitHub, 싱글플레이, C# 코드)과 맞지 않는 패키지가 포함되어 있다.

## Decision
- 삭제: `Assets/TutorialInfo/`, `Assets/Readme.asset` (다른 에셋의 참조 없음 확인)
- 패키지 제거: `com.unity.collab-proxy`(Unity Version Control), `com.unity.multiplayer.center`, `com.unity.visualscripting`
- 유지(보류): Mobile 품질 레벨과 `Mobile_RPAsset`/`Mobile_Renderer`(QualitySettings가 참조, 품질 프로필 설계 미정), `SampleScene`, `InputSystem_Actions`(M1에서 교체 검토)

## Consequences
- 커밋 c1692be. Unity가 `packages-lock.json`을 다시 생성했고, 재컴파일 오류 0건을 Editor.log로 확인.
- Mobile 품질 레벨 정리는 URP 품질 프로필을 정할 때 다시 검토한다.
