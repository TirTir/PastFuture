# ADR-564 Unity 타입 이름 충돌 처리: 전체 이름 사용

- Status: Accepted
- SourceStep: 17 / M0 (2026-11-25, 사용자 승인)
- Related: ADR-479, ADR-563 / Handover 16-18 (`PastFuture.Editor.Build.BuildWindows` 예시)

## Context
어셈블리와 rootNamespace를 Handover 계층 이름(`PastFuture.Application`, `PastFuture.Editor`)으로 정하면, `PastFuture.*` 안에서 bare `Application`/`Editor`가 우리 네임스페이스로 해석되어 `UnityEngine.Application`, `UnityEditor.Editor` 사용 시 컴파일 오류가 난다.

## Decision
Handover의 이름을 유지한다. Unity 쪽 타입은 항상 `UnityEngine.Application`, `UnityEditor.Editor`처럼 전체 이름으로 쓴다. 규칙은 `Docs/DevelopmentRules.md` 4절과 `CLAUDE.md`에 둔다.

## Alternatives
- 네임스페이스를 `PastFuture.App`, `PastFuture.EditorTools`로 변경: 충돌은 없지만 Handover 문서의 이름과 어긋남.

## Consequences
- 문서와 코드의 이름이 일치한다.
- 전체 이름을 빠뜨리면 컴파일 오류로 바로 드러난다 (조용한 오동작은 없음).
