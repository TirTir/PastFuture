# ADR-565 PlayMode 테스트 어셈블리는 M1에서 생성

- Status: Accepted
- SourceStep: 17 / M0 (2026-11-25, 사용자 승인)
- Related: Handover 16-17 폴더 구조(`Assets/Tests/{EditMode,PlayMode}`), 16-18, 4절 M0/M1

## Context
M0 완료 기준은 EditMode/순수 C# smoke이며, PlayMode가 필요한 입력·물리·카메라 검증은 M1 범위다.

## Decision
M0에서는 `PastFuture.Tests.EditMode`만 만든다. `PastFuture.Tests.PlayMode`는 M1에서 첫 PlayMode 테스트와 함께 만들고, 그때 `AssemblyBoundaryTests`의 허용 표에 등록한다.

## Consequences
- M0에는 빈 PlayMode 어셈블리가 없다.
- M1 시작 시 asmdef와 경계 테스트 갱신이 필요하다.
